Set up “Listen” (once)

iPhone's built-in Shazam does the listening. A Shortcut named ChangAlong passes the song to this page.

Quick way: let AI build it

Copy this prompt and paste it into the AI shortcut builder in the Shortcuts app (or any assistant that can create shortcuts).

Or build it by hand (4 actions)
  1. Recognize Music
  2. URL Encode: tap its input → Shazam Media → tap the bubble again → Title.
  3. Text: then insert URL Encoded Text right after the =.
  4. Open URLs with Text as input. Name the shortcut exactly ChangAlong.

Tip: Settings → Accessibility → Touch → Back Tap → Double Tap → ChangAlong.
