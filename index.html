Set up “Listen” (once)

iPhone's built-in Shazam does the listening. A Shortcut named ChangAlong passes the song to this page.

Quick way: let AI build it

Copy this prompt and paste it into the AI shortcut builder in the Shortcuts app (or any assistant that can create shortcuts).

Or build it by hand (4 actions)
  1. Recognize Music
  2. URL Encode: tap its input → Shazam Media → tap the bubble again → Title.
  3. Text: then insert URL Encoded Text right after the =.
  4. Open URLs with Text as input. Name the shortcut exactly ChangAlong.

Tip: Settings → Accessibility → Touch → Back Tap → Double Tap → ChangAlong.

What the tags mean

Each song shows one grey tag. It tells you how precisely the lyrics are timed. That depends on the lyrics file, not on the app.

Word synced
Every word has its own start time. The highlight follows the real rhythm: it lingers on held notes and speeds through fast parts. Best experience.
Synced
Only each line has a start time. Lines appear exactly on time, but the highlight sweeps evenly across the line, so it won't stretch on a long note.
Lyrics only
No timing at all. Tap Next line as you sing to move along. Try Other versions (tap the song title) for a synced one.

Other tags

Duet
The lyrics mark who sings each line, so lines are colour-coded (see below).
Live Remix
A different version from the studio one (also Acoustic, Instrumental, Cover). Its timing may not match what the KTV plays.
繁→简
The lyrics were in Traditional characters and were converted to Simplified. Turn this off in Settings → Characters.
Cantonese
Showing jyutping instead of pinyin, for songs sung in Cantonese. Switch in Settings.
No pinyin
The song isn't in Chinese, so it's shown as plain text (also Japanese Korean).
