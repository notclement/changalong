Set up “Listen” (once)

iPhone's built-in Shazam does the listening. A small Shortcut passes the song name to this page.

  1. Open the Shortcuts app, tap +, and name the shortcut exactly ChangAlong.
  2. Add Recognize Music.
  3. Add Get Details of Shazam Media → Title. Then add URL Encode. Add Set Variable named T.
  4. Add Get Details of Shazam Media → Artist (tap the input and pick Shazam Media again), then URL Encode, then Set Variable named A.
  5. Add Text with:
  6. Add Open URLs. Done. Tip: Settings → Accessibility → Touch → Back Tap → Double Tap → ChangAlong.
